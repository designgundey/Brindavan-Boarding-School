Brindaban Boarding School website

Includes editable HTML, CSS, JavaScript and image assets. No build or dependencies required.

Preview: open a terminal in this folder and run python3 -m http.server 8000, then visit http://localhost:8000.

Hosting: upload these files to the root of any static website host.

Fonts load from Google Fonts. Research sources and image attribution are included in the website footer. School details and official branding require confirmation before official public use.
